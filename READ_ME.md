## Installation 

Clone the repository :
git clone https://github.com/Ocedy16/Interpretability-Rieman-BCI.git
cd Interpretability-Rieman-BCI

Install the required dependencies :
pip install -r requirements.txt
Warning : Windows users may experience trouble downloading the cuda packages. A Linux installation is strongly advised.

## Reproducing the results

Reproducing_and_exploring.ipynb helps understand the functions to call to compute PFI and Shapley on MOABB or other datasets. Visualization is also available to reproduce the article's figures.
